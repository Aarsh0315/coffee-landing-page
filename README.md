# ☕ The Coffee Cup

A modern and responsive coffee landing page built using HTML and CSS.

## 🚀 Features

- Responsive Navbar
- Hero Section
- Services Section
- Coffee Menu Cards
- Customer Testimonials
- Modern Footer
- Responsive Layout
- Clean UI Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts
- Font Awesome
